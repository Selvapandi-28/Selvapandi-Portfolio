# Selvapandi P. - Portfolio Website

A modern, responsive portfolio website showcasing full-stack Java development, AI integrations, data analytics, and cloud engineering projects.

## Project Structure
- `index.html` — The main website entrypoint with Tailwind CSS and interactive UI
- `vercel.json` — Vercel configuration for static routing and clean URLs
- `package.json` — Project metadata

---

## 🚀 How to Deploy on Vercel

### Option 1: Via GitHub (Recommended)
1. Push this folder to a GitHub repository:
   - Go to [github.com/new](https://github.com/new) and create a new repository named `selva-portfolio`.
   - Upload the files in this folder (`index.html`, `vercel.json`, `package.json`).
2. Go to [vercel.com/new](https://vercel.com/new).
3. Connect your GitHub account and click **Import** next to `selva-portfolio`.
4. Leave framework preset as **Other** (Root Directory `./`) and click **Deploy**.
5. Your portfolio is live with a free `.vercel.app` URL and automatic updates on every push!

### Option 2: Direct Upload / Drag & Drop
1. Go to [vercel.com](https://vercel.com) and log in.
2. Under your dashboard, click **Add New...** -> **Project**.
3. If using Vercel CLI:
   ```bash
   npm i -g vercel
   vercel
   ```
4. Follow the prompts (Select `./`, confirm deployment).
